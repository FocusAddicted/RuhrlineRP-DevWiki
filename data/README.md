# Runtime data

Der Explorer lädt die GTA-V-Datensätze standardmäßig live aus:
https://github.com/DurtyFree/gta-v-data-dumps

Die Quell-URLs und Kategorien stehen in `js/catalog.js`.

Wenn eine vollständig offline nutzbare Version gewünscht ist, können die dort referenzierten Dateien in diesen Ordner kopiert und `RL_CATALOG.base` in `js/catalog.js` auf `data/` geändert werden.
